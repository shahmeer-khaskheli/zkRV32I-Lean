# Grant Readiness

## Technical evidence

The project has a passing Lean build and repository verification gate, source
integrity scans, host Rust tests, adversarial mutation tests, and bounded
formal proof evidence.

The current gate must be used as the exact evidence record. The repository
does not claim independent security review, certification, production
deployment, or a complete cryptographic system.

## Eligibility

Funding eligibility, institutional participation, publication plans, budgets,
and independent review remain administrative questions outside this
repository. They should not be inferred from passing tests or a Lean build.
